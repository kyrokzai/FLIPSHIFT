# FORMIQ TALENT AGENT

**Intelligence in Motion**

Talent Agent — ИИ-платформа поиска и подбора сотрудников для бизнеса. Работодатель описывает обычными словами, кого ищет; платформа собирает структурированную вакансию, уточняет недостающее и готовит подбор кандидатов. Разработчик — FORMIQ.

> «Мне нужны два бариста в Астане, зарплата 300 000 тенге, график 5/2» → вакансия с должностью, городом, оплатой и графиком и три уточняющих вопроса: опыт, обязанности, ИИ-интервью.

## Что работает сейчас

Пилот одной вакансии — от фразы работодателя до шорт-листа:

- главная страница с полем ввода; черновик вакансии создаётся без регистрации;
- разбор запроса на русском языке, уточняющие вопросы, правки текстом и вручную;
- исключение защищённых признаков (пол, возраст и другие) с объяснением;
- поисковые запросы по вакансии и переход к поиску резюме на hh.kz, Enbek.kz и в LinkedIn под учётной записью работодателя;
- реестр источников: что доступно, что требует аккаунта, API или оплаты, что запрещено;
- импорт резюме — PDF, DOCX, TXT или текст — с источником и ссылкой на оригинал;
- анализ резюме, сравнение с вакансией по критериям с дословными выдержками, шорт-лист с объяснениями;
- вопросы для предварительного интервью: общие и по пробелам каждого резюме;
- статус каждого шага: успешно, ошибка, требуется доступ, не подключено;
- режимы DEMO (вымышленные кандидаты) и LIVE (только добавленные работодателем), которые не смешиваются.

Чего нет и что интерфейс не изображает:

- автоматического поиска по площадкам — законного способа получить резюме без доступа работодателя нет, подробности в [SOURCING.md](docs/SOURCING.md);
- автоматического ИИ-интервью — вопросы готовит агент, задаёт работодатель;
- аккаунтов и серверной базы — всё хранится в браузере работодателя.

Без языковой модели резюме читается и анализируется в браузере и на сервер не передаётся.

## Запуск

Нужен Node.js 22.12 или новее.

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:3000`. Настройки не обязательны: по умолчанию работает встроенный движок разбора, внешние сервисы не вызываются.

### Подключение языковой модели

Скопируйте `.env.example` в `.env.local` и задайте:

```bash
AI_PROVIDER=anthropic
ANTHROPIC_API_KEY=...       # ключ хранится только в окружении, не в Git
AI_MODEL=claude-opus-5-5    # необязательно
```

Это платный API. Модель вызывается один раз на свободное сообщение работодателя и один раз на резюме в режиме LIVE; ответы кнопками и режим DEMO обходятся без неё. С подключённой моделью текст резюме без контактов передаётся на сервер и в модель — для настоящих резюме на это нужно согласие кандидатов.

## Проверки

```bash
npm run lint        # ESLint
npm run typecheck   # проверка типов
npm test            # модульные тесты
npm run test:e2e    # сквозные тесты: десктоп и профиль iPhone
npm run build       # производственная сборка
```

Сквозным тестам нужен браузер Chromium для Playwright: `npx playwright install chromium`.

## Стек

Next.js 16, React 19, TypeScript 6, Tailwind CSS 4, Zod 4, Vitest, Playwright. На этапе H3 добавляются PostgreSQL, Drizzle ORM и Better Auth. Деплой планируется на Vercel.

## Правила платформы

1. Окончательное решение о найме принимает работодатель.
2. Защищённые личные признаки не используются для отбора.
3. ИИ-интервью проводится только с согласия кандидата.
4. Кандидаты — только из разрешённых источников, без обхода ограничений площадок.
5. Платформа не имитирует действия, которых не совершала.
