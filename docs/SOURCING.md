# Источники кандидатов: что доступно законно

Проверено 17.11.2026 для пилота в Астане. Документ фиксирует, откуда Talent Agent может получать кандидатов, что для этого нужно и чего платформа не делает.

## Главный вывод

Ни одна площадка в Казахстане не отдаёт резюме автоматически без учётной записи работодателя. Автоматический сбор страниц запрещён правилами hh.kz, Enbek.kz и LinkedIn. Поэтому в пилоте работает честный режим **поиска с помощью агента**:

1. Агент составляет поисковые запросы по вакансии.
2. Работодатель открывает поиск на площадке под своей учётной записью — по ссылке из Talent Agent.
3. Найденные резюме работодатель добавляет в Talent Agent файлом или текстом, с названием источника и ссылкой на оригинал.
4. Агент анализирует резюме, сравнивает с вакансией, собирает шорт-лист и вопросы для интервью.

**Автоматически получено настоящих кандидатов: 0.** Это не сбой, а результат проверки: законного способа получить их без доступа работодателя нет.

## Как читать пометки

- **проверено запросом** — страница или файл открыты напрямую 17.11.2026;
- **официальный репозиторий** — текст взят из `github.com/hhru/api`;
- **по выдержке** — официальная страница видна только в выдаче поисковика, сама страница не открывалась;
- **не проверено** — подтверждения нет, нужно проверить отдельно.

Сайты `api.hh.ru`, `dev.hh.ru` и `hh.kz` из среды разработки были недоступны, поэтому по HeadHunter нет ни одной проверки живым запросом.

## Ссылки на поиск, которые открывает Talent Agent

| Площадка | Адрес | Что передаётся | Пометка |
|---|---|---|---|
| hh.kz | `https://hh.kz/search/resume?text=<запрос>&area=<регион>` | Запрос целиком, с операторами AND / OR. Регион: Астана — 159, Алматы — 160 | адрес — по выдержке; номера регионов подтверждены сторонним справочником, официальным запросом не проверены |
| Enbek.kz | `https://www.enbek.kz/ru/search/resume?prof=<должность>&region_id=<регион>` | Самое распространённое название должности. Регион: Астана — 71, Алматы — 75 | проверено запросом 17.11.2026: «менеджер по продажам», Астана — 3 013 резюме |
| LinkedIn | `https://www.linkedin.com/search/results/people/?keywords=<должность отрасль город>` | Название должности, отрасль и город | обычный поиск людей в аккаунте работодателя |

Для городов вне списка регион не подставляется — его выбирают на самой площадке.

На Enbek.kz и в LinkedIn уходит короткое название должности, а не длинный запрос: поле поиска там простое, и длинная строка даёт пустую выдачу.

**Перед встречей** откройте «Искать на hh.kz» и убедитесь, что выбран регион Астана. Сайты HeadHunter из среды разработки недоступны, поэтому номер региона 159 подтверждён только сторонним справочником идентификаторов hh.

## Что нужно для автоматического поиска

1. **Enbek.kz уже сейчас, бесплатно.** Заказчик регистрируется как работодатель и подтверждает ЭЦП компании — получает полный доступ к резюме и контактам. Автоматизировать просмотр нельзя; рабочий сценарий — поиск по запросам агента и импорт подходящих резюме.
2. **hh.kz, отклики.** Подать заявку на приложение на dev.hh.kz от имени FORMIQ. После одобрения (до 15 рабочих дней) Talent Agent сможет загружать отклики на вакансии заказчика автоматически, с его согласия через OAuth. Это самый быстрый путь к настоящей автоматизации.
3. **hh.kz, поиск по базе.** После подключения приложения проверить `method_access` для компании заказчика: станет ясно, нужен ли платный доступ.
4. **Enbek.kz, соглашение.** Направить запрос в АО «ЦРТР» о возможности интеграции.

## Персональные данные: закон Республики Казахстан № 94-V

Проверено запросом по [тексту закона](https://adilet.zan.kz/rus/docs/Z1300000094). Это не юридическое заключение — до запуска LIVE с настоящими данными нужна проверка юристом.

- **Ст. 7, п. 1.** Сбор и обработка персональных данных требуют согласия субъекта. Исключения из ст. 9 подбор персонала не покрывают.
- **Ст. 7, п. 3-1.** Если человек сам опубликовал данные, законность их дальнейшего сбора обязан подтвердить тот, кто собирает. Публичное резюме не становится свободным для использования.
- **Ст. 8.** Согласие должно быть подтверждаемым и содержать оператора, срок, передачу третьим лицам, трансграничную передачу и перечень данных.
- **Ст. 12, п. 2.** Персональные данные хранятся в базе, находящейся на территории Республики Казахстан.
- **Ст. 16.** Трансграничная передача — только в государства с должной защитой или с согласия субъекта.

Что из этого следует для пилота:

- В пилоте резюме читается и анализируется в браузере работодателя и хранится только в нём. На сервер резюме не передаётся — это проверяется автоматическим тестом.
- Если подключить языковую модель, текст резюме без контактов и личных строк будет уходить на сервер и в модель за пределы Казахстана. Для настоящих резюме на это нужно согласие кандидатов.
- База кандидатов на сервере (этап H3) должна размещаться в Казахстане, с записью согласия по каждому кандидату.
